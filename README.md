# Nurse Credentialing Model (demo)

An interactive demo of a multi-state RN and LVN credentialing process, built by Aleena Maryam.

It shows:

- Which state licenses a nurse needs, based on where they live and where their patients are, including the Nurse Licensure Compact and the 60-day rule when a nurse moves
- A credential file where every check carries a date, a source, evidence and the person who recorded it
- An audit log of every change
- A scheduling gate: a nurse is cleared only after a second person, who recorded none of the checks, signs off
- Monthly exclusion screening, license renewals and a scorecard
- Built-in tests of the licensing rules

All candidates are invented examples. Nothing is saved: the page resets when you close it.

## Put it online with GitHub Pages

1. Sign in at github.com (or create a free account).
2. Click **New repository**. Name it, for example, `credentialing-demo`. Choose **Public**, then **Create repository**.
3. Click **uploading an existing file**, drag in `index.html` and this `README.md`, then click **Commit changes**.
4. Go to **Settings**, then **Pages**. Under **Branch**, choose `main` and `/ (root)`, then **Save**.
5. After a minute or two, the page shows your link, for example `https://yourname.github.io/credentialing-demo/`.

To update it later, upload a new `index.html` to the same repository.
